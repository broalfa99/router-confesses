A single line a home Wi-Fi router would say to excuse itself for dropping
the connection at the exact moment a movie reaches its climax, written for
the [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e)
bounty on [make.fun](https://make.fun).

## The line

> I saw the killer's face first. Then I panicked and dropped you. You're welcome.

## Run it

```sh
node main.ts
```

`main.ts` writes the line (79 characters, one line) to `/output/entry.txt`.
The bounty gate requires 1–200 characters of UTF-8 text. The program
verifies the write by reading the file back and confirming it matches.
